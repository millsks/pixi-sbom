    1.11.0 - 2026-10-10¶

    Features¶

    • identity: CRAN purls for R packages (#494) (eb06bef)
    • prefix: Go modules from the build info of Go binaries (#495) (fd9fb46)
    • prefix: Npm packages installed in the environment (#496) (4e6a6fa)

    Documentation¶

    • examples: R, Go and npm example environments (#500) (dff7d73)
    • Edit the 1.11.0 notes in What's new (#501) (e8fd572)

    CI and Build¶

    1.10.0 - 2026-10-10¶

    Features¶

    • identity: Curated CPEs for native conda packages (#467) (7311c0f)
    • prefix: PyPI identity of conda packages from their installed dist-info (#468) (8238f49)
    • prefix: The interpreter of a plain Python installation as a component (#469) (17da7a1)
    • prefix: Python distributions vendored inside packages (#473) (a9dddc0)
    • identity: Warn when scanners would miss conda packages' PyPI identity (#479) (ace6cb7)
    • prefix: Verify installed files against conda-meta (#480) (f32ad51)
    • output: GitHub dependency submission format (#483) (ed39b38)
    • cli: Group --help flags into sections drawn as rules (#486) (e4c402d)

    Bug Fixes¶

    • prefix: Read site-packages once through conda-forge's lib/python3.1 symlink (#465) (c7488fd)
    • prefix: Record the environment's platform, not the host's (#466) (3b54105)
    • cpe: Use the conda-forge names of four table entries (#472) (849b628)
    • licenses: Never add a version to an unversioned license name (#474) (2164d3a)
    • quality: Grade other tools' documents on the same terms (#475) (dfa36b2)
    • prefix: No machine-local absolute paths in a document (#476) (625ff92)
    • identity: No scanner warning for reports and GitHub snapshots (#484) (f3fa190)
    • cli: Sort completion candidates alphabetically (#485) (ffa25c0)
    • prefix: No machine path in a local pixi:direct-url (#487) (baa15b8)
    • prefix: A relative --prefix keeps the project's paths portable (#488) (346069d)

    Documentation¶

    • Pixi-sbom and syft side by side (#477) (c9bf038)
    • Edit the 1.10.0 notes in What's new (#490) (69b716f)

    Testing¶

    • Compare Grype findings from pixi-sbom's SBOM against syft's (#470) (b9185c9)
