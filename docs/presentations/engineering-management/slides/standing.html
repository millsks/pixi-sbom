Where the project is

Version 0.10.1, with a changelog and release builds for five platforms

Installs the way our other tools do: pixi global install pixi-sbom

A docs site, a troubleshooting guide, and a diagnostic mode for locked-down networks

Speed and memory measured on all five platforms at every release, numbers published

At 1.0 the flags, exit codes and output fields come under a written stability promise

Apache-2.0, so we can read it, fork it, or fix it ourselves

This slide is here to answer the question nobody says out loud: is this somebody's weekend project that we'll regret depending on. The stability promise is the strongest item for management, because it's an explicit commitment about what won't change without a major version — more than most of our internal tooling offers. If we'd be the ones maintaining it, say so directly. Being the maintainer is a strength here as long as you're honest about the bus factor when somebody asks.
