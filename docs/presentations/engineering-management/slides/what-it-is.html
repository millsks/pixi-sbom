These four tiles answer the questions an operations-minded manager asks before anything else: how big is it, where does it run, what does it talk to, and what happens on a locked-down network. Nothing gets sent anywhere. The vulnerability lookups are flags you turn on, and with them off it never opens a socket. Behind a proxy or on an air-gapped box it runs from a warm cache and records in the document what it couldn't reach, which is exactly what an auditor wants to see.
