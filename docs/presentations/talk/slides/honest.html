What it does not do

Prove you are safe

It finds what is already published. An advisory that does not exist yet is not in any database.

See what is not locked

Vendored code, a binary copied into the image, a package installed by hand: the lockfile does not name them.

Decide reachability

A finding means a vulnerable version is present, not that your code calls it. VEX records that judgment; it does not make it.

Replace the mapping

The PyPI identity is only as good as conda-forge's mapping. Where there is none, it says so.

[5-minute cut: one line ("it finds what is published, in what is locked"). Full talk: 11:30–12:30.] Say this plainly; a security audience trusts a tool more when it states its edges. The mapping point: packages from other channels or private builds may have no PyPI identity, and the document then carries only the conda one, with no guess.
