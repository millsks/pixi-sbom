# Posts

Announcements written to be posted elsewhere: the pixi Discord, a blog, a mailing list. They're
kept here, next to the code they describe, so a claim in one can be checked against the docs and
corrected when the tool changes.

These are excluded from the documentation site (`exclude_docs` in `mkdocs.yml`). The site's own
account of each release is [What's new](../whats-new.md); a post is the short, shareable version of
it, and links back there for the detail.
