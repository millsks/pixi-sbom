# Lab cache

What the online services answered when the [training lab](../../docs/lab.md)'s commands were run on 2026-10-09: OSV advisories, the CISA KEV catalog, FIRST EPSS scores and PyPI release metadata for the packages its 15 commands look up. The lab sets `PIXI_SBOM_OFFLINE=1` and points `PIXI_SBOM_CACHE_DIR` here, so everyone who takes it gets these answers.

Recorded by `pixi run lab-cache` (`scripts/lab_cache.py`). It is generated: do not edit it by hand.
